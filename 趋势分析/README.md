# 消石灰制备 · 趋势分析

离线数据可视化工具，双击 `index.html` 即用（无网络依赖）。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 分析界面（测点选择、多曲线叠加、缩放、统计卡、直方图、概览表） |
| `data.js` | 预处理后的全量数据（模拟量分钟均值、开关量变化点、分布统计） |
| `echarts.min.js` | 本地图表库 |
| `build_data.py` | 预处理脚本，纯标准库，`python build_data.py` 重跑 |

## 更新数据

新的 zip / 测点清单 CSV 放入 `../脱硫脱硝消石灰制备数据/` 后重跑：

```bash
python build_data.py
```

数据约定：zip 内为 `tagID_*.csv`（首行测点名+描述，数据行 时间/值/状态）；无效点为 1970 时间戳，自动过滤；跨包重叠按时间去重；开关量以值域 ⊆{0,1} 判定（清单「点类型」列不可信）。
