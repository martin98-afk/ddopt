# FOPDT+DMC 对比实验

在消石灰制备（水率 → T3）对象上尝试 FOPDT 辨识 + DMC 控制，
与现行规则控制器、人工操作在同一仿真环境对比。

## 结论（先行）

**FOPDT+DMC 输给现行规则控制器 4.7 个百分点（88.8% vs 93.5%，
人工 94.7%），且输因是结构性的，调参无法挽救。**

| 方案 | T3 合格率 | 稳态 σ | 动作次数 |
|---|---|---|---|
| 人工（实际轨迹） | 94.7% | 8.99 | 9 |
| 现行规则控制器 | 93.5% | 8.69 | 1 |
| FOPDT+DMC | **88.8%** | 10.45 | 6 |

DMC 的水率一路被推到操作带下限 570 并触底；λ 从 0.01 扫到 10
（四个量级）结果完全不变——每拍动作都被步长限幅顶满，控制权被
模型失配主导。

## 为什么输

1. **水率→T3 是非最小相位**：加水后 T3 先升（+46.8℃/100L/t @5min）
   后降（稳态 −15.1℃/100L/t）。FOPDT 的单调阶跃响应从数学上就
   表达不了符号反转。
2. 拟合结果 R² 只有 0.53（K=−0.266、τ=2.7min、θ=16min）：τ 被迫
   缩到 2.7min 去凑响应核的深谷，模型认为"加水后 3 分钟就该见效"。
3. 真对象里加水后 T3 反而升 → DMC 的 bias 校正把它当成巨大正偏差
   → 继续加水（模型说该降温）→ 实测继续升 → 恶性循环触底。
   **控制器在与非最小相位对抗，而不是在控制过程。**
4. 现行规则控制器的"节拍式等待"（动作后 35 min 不评估）正是针对
   这个反向期设计的：等反向期过去再评估，就不会被假象带偏。

> **2026-10-20 补注：上面的"非最小相位"前提本身存疑。**
> 核的前段正响应高度疑似辨识伪影——操作员在 T3 上升途中才加水
> （反馈行为），事件研究把滞后窗口内的原趋势延续误标为加水的
> 升温响应。证据与物理量级分析见 `../模型/README.md` 3.1 节修正。
> 本实验的准确表述应为：**用这个（疑似伪影的）核做 FOPDT+DMC
> 必然输**——伪影核不能支撑任何预测控制；它同时反证了现行
> "只信 35min 后稳态效应"的节拍策略对核的真伪稳健。

## 实验设置

- 真对象：响应核 G_OLD（10-12~10-19 十二个水率阶跃事件辨识，
  README 权威口径；前段正、k≈16 过零、稳态 −0.151 ℃/(L/t)）
- 扰动：共同随机数法，d[t] = 实际 T3 − G∘(实际水率)，三方共用
- 班次：当前宽表仅切出 1 个 ≥150min 生产段（568 分钟，10-19 16:34）
  作为对比场景；现场重辨识对照只认出 2 个事件且稳态 −0.84（数据
  口径已变，不可信，故不采用）
- DMC：Ts=10min、P=18、M=3、解析解滚动优化、MV∈[570,690]、
  步长 ±15 L/t、bias EMA（τ=3 拍）
- 合格率口径：T3∈[100,130]℃

## 文件

| 文件 | 作用 |
|---|---|
| `fopdt.py` | 响应核 → FOPDT 拟合（θ 网格 + τ 精修）、阶跃系数、动态矩阵 |
| `dmc.py` | 最小 DMC（单 MV 单 CV，解析解 + bias 校正） |
| `run_experiment.py` | 三方对比主实验 + λ 敏感性 + 轨迹诊断 |

运行：`python run_experiment.py`（依赖 `../模型` 的数据加载与 A/B 框架）

## 局限

1. 模型内自证：真对象是响应核（12 个阶跃样本），若核有偏结论有偏
2. 只有 1 个对比班次；班次间扰动差异未覆盖
3. DMC 未做非最小相位补偿（如用反向响应核建分离模型、二阶+右半零点
   结构），若真要救 DMC 应从这里入手，但样本量（12 个事件）撑不起
4. 电流约束未纳入 DMC（现行方案里电流走独立规则，天然解耦）
