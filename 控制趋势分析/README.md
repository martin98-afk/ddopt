# 消石灰制备 · 控制趋势分析

在「趋势分析」基础上，**额外叠加模型的三个输出设定值**，
用于直观对比「现场实际/原有设定」与「模型输出」的差异。

双击 `index.html` 即用（无网络依赖）。

## 与原「趋势分析」的区别

| 项目 | 趋势分析 | 控制趋势分析 |
|---|---|---|
| 原始测点 | 47 个 | 47 个（完全一致） |
| 模型输出测点 | 无 | **+3 个** |
| 测点分组 | 模拟量 / 开关量 | **模型输出** / 模拟量 / 开关量 |
| 默认打开显示 | 两个料位 | 三组对照曲线 |

## 新增的三个测点

| 测点名 | 含义 | 单位 | 对应原测点 |
|---|---|---|---|
| `MODEL_RATIO` | 模型水率设定 | L/t | `5#_XSH_SL(SHB)SD` |
| `MODEL_LIME` | 模型生石灰流量设定 | t/h | `5#_XSH_SSHLLSJZ` |
| `MODEL_WATER` | 模型水流量设定 | L/h | `5#_XSH_SLLSJZ` |

三个量满足：`MODEL_WATER = MODEL_RATIO × MODEL_LIME`
（水率即水灰比 = 水流量 ÷ 生石灰流量）

打开页面默认加载这六条曲线（三条原值 + 三条模型值），可直接对比。

模型测点在侧栏以**绿色**标识，单独成组并置顶。

## 覆盖范围

模型输出只在**稳态段**有值（非生产段与启动段不输出）：

- 时间范围：10-12 22:34 ~ 10-19 03:03
- 有效点：2002 分钟（6 个班次的稳态段）
- 生产判据：给水给料允许信号 = 1

启动段（每班次前 120 分钟或 T3 < 100℃ 期间）模型沿用现场参数，
不产生独立输出，故无值。

## 重新生成数据

模型输出由 `../模型/export_model_tags.py` 生成。改了模型参数后：

```bash
cd ../模型
python export_model_tags.py        # 生成 .cache/model_tags.json

cd ../控制趋势分析
python build_data.py               # 合并原始测点 + 模型测点 -> data.js
```

若 `../模型/.cache/model_tags.json` 不存在，`build_data.py` 会跳过合并，
仅生成原始测点，脚本仍可独立运行。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 分析界面（测点选择、多曲线叠加、缩放、统计卡、直方图、概览表） |
| `data.js` | 预处理后的全量数据（原始测点 + 模型输出） |
| `echarts.min.js` | 本地图表库 |
| `build_data.py` | 预处理脚本，纯标准库 |

数据约定沿用原版：zip 内为 `tagID_*.csv`；无效点为 1970 时间戳，自动过滤；
跨包重叠按时间去重；开关量以值域 ⊆{0,1} 判定（清单「点类型」列不可信）。
